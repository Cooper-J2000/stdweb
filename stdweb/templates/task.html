初始检查与掩模 {% if user_may_submit %}

在此阶段，将从 FITS 头中提取若干重要参数（增益、饱和值、滤光片名称等），并将目标名称解析为坐标，供后续强制测光使用。所有值均可通过填写表单覆盖。

可列出多个目标，每行一个。第一个为主目标，其余目标可用于在其周围额外位置进行强制测光。每个目标可用 Simbad 或 TNS 可解析的名称定义，或用常见格式的坐标字符串（十进制度数，或 HH MM SS DD MM SS 等）。

掩模由图像中的 NaN 值、超过饱和值的像素以及可选的宇宙线检测结果生成。宇宙线检测并不总是完美，如果它开始掩盖真实恒星请将其禁用！如果图像周围有不可用区域（如过扫描区），可使用自定义掩模编辑器手动掩模。

清理操作将删除除图像本身外的所有处理结果和设置。归档只删除生成的文件，但保留设置，以便用完全相同的配置重复处理。

原始图像可通过危险操作下的功能修改。在那里可以裁剪图像（使用实际像素坐标或边缘偏移），或将精化/盲匹配后的 WCS 写入头部，从而下载具有正确天体测量的图像。此外，可以复制任务，或在完成此图像后将其完全删除。

测光与天体测量 {% if user_may_submit %}

目标检测由第一行参数控制。此处的 S/N 同时影响误差过大的检测剔除和星等极限估算。

第二行控制检测到目标位置处的孔径测光。孔径大小（以及可选的天光背景估算环）以检测阶段测得的平均 FWHM 为单位指定。也可以在此手动覆盖 FWHM 值。

光度定标（第三行）取决于主滤光片和参考星表的选择。星表将从 Vizier 下载，可选择仅保留亮于给定星等的恒星。星表不宜比图像深太多，否则可能导致虚假匹配。光度解将使用指定的零点空间依赖多项式阶数，如需要还会使用与所选星表相关的颜色项。支持的星表与滤光片：

上述所有 Johnson-Cousins（U, B, V, R, I）、2MASS（J, H, Ks）和 Gaia（G, BP, RP）滤光片的光度系统（零点）为 Vega，Sloan 类（ugrizy）滤光片为 Pan-STARRS（u 除外，为 SDSS），与实际选择的星表无关。

天体测量精化利用检测目标的位置和参考星表来精化 FITS 头中的现有天体测量解。结果保存到文件，并在后续处理中复用。如果没有初始天体测量解，可启动 WCS 盲匹配。该过程可限定到天空的特定区域以及像素比例范围。

简单暂现源检测 {% if user_may_submit %}

基于星表的简单暂现源检测可找出与图像中其他目标分离良好、因此在原始（未相减）图像中易于检测的暂现源。算法使用光度定标阶段检测到的目标列表，剔除与常见星表（Gaia eDR3、Pan-STARRS DR1、SkyMapper DR4 等）恒星匹配的对象。此外，所有被标记的目标（即孔径内包含被掩模像素的）以及测光预过滤（基于机器学习的形状分类器）阶段剔除的对象都会被排除。还会运行额外例程剔除混合源，并使用 SkyBoT 服务检查候选体是否与已知太阳系天体位置重合。

例程会将暂现源候选体的亮度与星表匹配对象比较，仅保留比星表亮用户指定极限的匹配，以避免在周围暗星过多的致密天区中造成混淆。如果未指定极限，所有位置匹配都会被剔除——当例程保留过多明显错误的候选体时请使用此功能。

为进一步缩小候选体列表，可指定搜索暂现源的天区（即使用指定中心和半径的简单锥形搜索）。还可以指定包含同一片天区图像的任务列表——它们将用于剔除未出现在其目标列表中的一切。这样，只会得到所有指定任务图像中都出现的候选体。

模板相减 {% if user_may_submit %}

模板既可以是上传的 FITS 文件（此时建议为其指定正确的增益和饱和值以确保相减可靠），也可以从以下在线来源下载：

    {% for tmpl in supported_templates.values %} {% if 'filters' in tmpl %}
  • {{ tmpl.name }} [{{ tmpl.filters|join:", " }}]
    • {% endif %} {% endfor %}
注意 HiPS 巡天没有针对饱和天体或瑕疵的掩模，结果可靠性会稍差。

为简化相减，图像将按指定大小拆分为子图。子图间按指定像素数重叠，以提高子图边缘附近相减例程的稳定性，但这些重叠区域会从实际暂现源检测中排除，因此输出中不会出现重复的暂现源。在目标测光模式下，仅选择目标周围单个子图。

图像相减由 HOTPANTS 处理。代码会自动为图像和模板创建合适的噪声图，并为相减选择最优 HOTPANTS 参数。当然，也可以通过 JSON 字符串覆盖或附加参数。最常调整的参数是 ko 和 bgo，它们控制用于构建相减模型的区域内卷积核与背景的空间阶数。

暂现源检测在差分图中进行，使用 HOTPANTS 生成的噪声模型和合并掩模。检测、测量参数以及候选体的光度定标与上面光度定标使用的相同。

暂现源候选体将经过过滤，剔除孔径内包含被掩模像素的候选体，以及与 Pan-STARRS DR1 和 SkyMapper DR1.1 星表中目标位置重合（半 FWHM 半径内）的候选体。
